# Formula 1 Race Explorer

An interactive Formula 1 web application that allows users to explore race, qualifying, driver, and constructor data across multiple F1 seasons.

## Live Demo

[View the Live Website](https://nzerp263.github.io/COMP3512Assignment2/)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- REST/API Data
- Git & GitHub

## Features

- Browse Formula 1 seasons and races
- Dynamically display race results
- View qualifying results
- View detailed driver information
- View constructor information and performance
- Interactive Bootstrap modals
- Dynamic DOM manipulation and event handling
- External data/API integration

## About the Project

This project was developed to demonstrate front-end web development concepts including asynchronous data handling, dynamic content generation, responsive interface design, and JavaScript-based user interaction.

The application retrieves and processes Formula 1 data and dynamically presents the information through an interactive web interface.
